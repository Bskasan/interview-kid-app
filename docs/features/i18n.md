# i18n — Turkish + English

## What the user sees

1. First launch: the app opens in the device language if it is Turkish or English,
   otherwise in Turkish. Every screen — Home, Exercise (including question prompts and
   answer captions), Result, all accessibility labels — is fully in that language.
2. The Home header shows a pill toggle with two segments, "Türkçe" and "English", each
   written in its own language. The active segment is filled (yellow) and bold.
3. Tapping the other segment switches the whole app instantly — titles, lesson cards,
   mascot speech, question content, screen-reader labels — with no restart and no flicker
   beyond the re-render.
4. The choice is remembered: killing and relaunching the app restores the chosen language
   (a sub-second flash of the device language can occur on cold start while storage loads).
5. In English, the timer's spoken label pluralizes correctly ("1 second left" / "12 seconds
   left"); Turkish uses its single form.

## How it works in code

- **`src/locales/tr.json` / `en.json`** — one file per language; top-level keys are the six
  namespaces (`common`, `home`, `exercise`, `result`, `errors`, `questions`). Interpolation
  uses `{{placeholder}}`; the only plural pair is `exercise.timeLeft_one/_other`.
- **`src/i18n/index.ts`** — creates the singleton: synchronous init (`initAsync: false`,
  bundled resources), device-locale detection via `expo-localization` `getLocales()`,
  `supportedLngs: ['tr','en']`, `fallbackLng: 'tr'`. Also installs the `intl-pluralrules`
  polyfill behind a `typeof Intl.PluralRules` guard (Hermes lacks it; Node does not).
  Imported first in `app/_layout.tsx` so translation is ready before any render.
- **`src/i18n/i18next.d.ts`** — `CustomTypeOptions` typed from `tr.json`: unknown keys fail
  `tsc`.
- **`src/store/settingsStore.ts`** — persisted zustand store (`settings-v1`); `language:
'tr' | 'en' | null` (null = follow device). `setLanguage` flips i18next immediately;
  `onRehydrateStorage` re-applies a stored choice on launch.
- **`src/components/LanguageToggle.tsx`** — the header pill; `radiogroup`/`radio` roles,
  `checked` a11y state, ≥48dp segments, labels from `common:language.*`.
- **`src/data/questions.ts`** — language-neutral question bank: ids per set/question, typed
  `labelKey`/`a11yKey` into the `questions` namespace, shape options derive their spoken
  label from `questions:shapeOption` + color/shape token entries (word order per language).
  `optionLabel(option, t)` / `optionA11yLabel(option, t)` are the accessors.
- **`src/api/lessons.ts` + `src/types/lesson.ts`** — the Lesson model carries
  `lessonNumber` + `author`; `LessonCard` composes the title at render time, so cached data
  is never language-stale. Persister buster bumped to `lessons-v2`.
- Components use `useTranslation(namespace)`; screens pass typed keys only.

## Edge cases handled

- Unsupported device language → Turkish (fallback), not a blank or mixed UI.
- Language switch with a populated, persisted lesson cache → titles re-render from neutral
  fields; no refetch needed, works offline.
- Missing key in one language → build-time failure: `tsc` (key not in tr.json) or the
  parity test (`__tests__/locales/messages.test.ts`: identical key sets, no empty values,
  identical `{{placeholders}}` per key).
- Question content integrity per language → `__tests__/data/questions.test.ts` resolves
  every prompt/option in both locales and asserts four unique spoken labels per question.
- Plural correctness on Hermes → runtime-guarded polyfill; device checklist covers "1
  second left".

## How to test manually

1. Set the device language to English → app opens in English; to Turkish → Turkish; to any
   third language → Turkish.
2. Tap the toggle on Home: every visible string switches immediately, including lesson
   titles and the offline banner (enable airplane mode to see it).
3. Enter a lesson in English: prompt, captions and (with TalkBack) spoken option labels are
   English; switch back on Home and re-enter: Turkish.
4. Choose English, kill the app, relaunch → still English.
5. With TalkBack: the toggle announces as radio buttons with checked state; the timer
   announces "N seconds left" / "Kalan süre N saniye".
